# Hello World – Next.js

Proyecto de práctica para el tutorial de uso básico de Git y GitHub.

## Cómo ejecutarlo

```bash
npm install
npm run dev   # abre http://localhost:3000
npm run build
npm start
```

## Variables de entorno

Crea un archivo `.env.local` (ignorado por Git), por ejemplo:

```
NEXT_PUBLIC_API_URL=https://api.ejemplo.com
```

Nunca subas `.env` ni secretos a GitHub.
